Umgekehrte Kurvendiskussion

Von gegebenen Punkten und Bedingungen zur Funktionsgleichung — mithilfe von Gleichungssystemen.

Beispiel 1 Drei Punkte bestimmen eine Parabel
Eine quadratische Funktion f(x) = ax² + bx + c hat genau 3 Unbekannte: a, b, c. Um sie zu bestimmen, brauchen wir genau 3 Bedingungen — zum Beispiel 3 Punkte auf der Kurve. Jeden Punkt setzen wir in die Funktionsgleichung ein → wir erhalten eine Gleichung. 3 Punkte = 3 Gleichungen = lösbares System.
Gegeben
P₁ P₁(0 | 1) Punkt auf der Kurve
P₂ P₂(1 | 0) Punkt auf der Kurve
P₃ P₃(3 | 4) Punkt auf der Kurve
Schritt 1 — Gleichungen aufstellen
Jeder Punkt bedeutet: f(x) = y. Wir setzen x und y ein und erhalten eine Gleichung mit a, b, c.
Ansatz
f(x) = ax² + bx + c
P₁(0 | 1) einsetzen: f(0) = 1
a·0² + b·0 + c = 1  →  c = 1
c ist sofort bekannt! Punkte auf der y-Achse geben c direkt.
P₂(1 | 0) einsetzen: f(1) = 0
a·1 + b·1 + 1 = 0  →  a + b = −1   (I)
P₃(3 | 4) einsetzen: f(3) = 4
a·9 + b·3 + 1 = 4  →  9a + 3b = 3  ÷3:  3a + b = 1   (II)
Schritt 2 — Gleichungssystem lösen
System (c bereits bekannt)
(I) a + b = −1
(II)3a + b = 1
(II) − (I): 2a = 2
a = 1
a in (I) einsetzen: 1 + b = −1
b = −2
Ergebnis: f(x) = x² − 2x + 1 = (x−1)²
f(x) = x² − 2x + 1

Beispiel 2 Kubische mit Extrempunkt und Punkten
Eine kubische Funktion f(x) = ax³ + bx² + cx + d hat 4 Unbekannte. Ein Extrempunkt liefert uns gleich 2 Gleichungen: f(xₑ) = yₑ und f′(xₑ) = 0. Mit 2 weiteren Punkten haben wir genug, um das System zu lösen.
Gegeben
HP H(0 | 2) Hochpunkt → f(0)=2 und f′(0)=0
P₁ P₁(−1 | 0) Punkt auf der Kurve (Nullstelle)
P₂ P₂(2 | −2) Punkt auf der Kurve
Schritt 1 — Gleichungen aufstellen
Der Hochpunkt liefert zwei Gleichungen: die Funktion selbst und die Ableitung (Steigung = 0 im Extrempunkt).
Ansatz
f(x) = ax³ + bx² + cx + d
f′(x) = 3ax² + 2bx + c
HP: f(0) = 2
a·0 + b·0 + c·0 + d = 2  →  d = 2
d ist sofort bekannt — der Hochpunkt liegt auf der y-Achse.
HP: f′(0) = 0 (Steigung im Extrempunkt)
3a·0 + 2b·0 + c = 0  →  c = 0
c ist auch sofort bekannt — weil xₑ = 0 sehr praktisch ist.
P₁(−1 | 0) einsetzen: f(−1) = 0
−a + b + 0 + 2 = 0  →  −a + b = −2   (I)
P₂(2 | −2) einsetzen: f(2) = −2
8a + 4b + 0 + 2 = −2  →  8a + 4b = −4  ÷4:  2a + b = −1   (II)
Schritt 2 — Gleichungssystem lösen
System (c=0, d=2 bereits bekannt)
(I) −a + b = −2
(II) 2a + b = −1
(II) − (I): 3a = 1
a = ⅓
a in (I): −⅓ + b = −2
b = −2 + ⅓ = −5/3
Ergebnis: f(x) = ⅓x³ − 5/3·x² + 2
f(x) = ⅓x³ − 5/3x² + 2

Beispiel 3 Symmetriebedingung reduziert das System
Hat eine kubische Funktion ihren Wendepunkt auf der y-Achse (bei x=0), dann sind die Koeffizienten b und d automatisch null: f(x) = ax³ + cx. Aus 4 Unbekannten werden so nur noch 2 — das System ist viel einfacher zu lösen.
Gegeben
WP W(0 | 0) Wendepunkt im Ursprung → b=0 und d=0
HP H(−1 | 2) Hochpunkt → f(−1)=2 und f′(−1)=0
Schritt 1 — Symmetrie ausnutzen
Ein Wendepunkt bei x=0 bedeutet f″(0)=0. Bei f(x)=ax³+bx²+cx+d ergibt sich f″(x)=6ax+2b, also 6a·0+2b=0 → b=0. Und da W auf der x-Achse liegt: f(0)=d=0 → d=0.
Vereinfachter Ansatz durch Symmetrie
f(x) = ax³ + cx
f′(x) = 3ax² + c
Nur noch 2 Unbekannte: a und c.
Schritt 2 — Gleichungen aufstellen
HP: f(−1) = 2
a·(−1)³ + c·(−1) = 2  →  −a − c = 2   (I)
HP: f′(−1) = 0
3a·(−1)² + c = 0  →  3a + c = 0   (II)
Schritt 3 — Gleichungssystem lösen
2×2 System
(I) −a − c = 2
(II) 3a + c = 0
(I) + (II): 2a = 2
a = 1
a in (II): 3·1 + c = 0
c = −3
Ergebnis: f(x) = x³ − 3x (b=0, d=0 durch Symmetrie)
f(x) = x³ − 3x
